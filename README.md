# Player Management App

### Project Description
The **Player Management App** is a React-based application designed for managing players within a limited budget. Users can view available players, add them to their selection, and track costs dynamically, with real-time notifications indicating budget constraints and selection limits. It’s an intuitive way to simulate a player auction or team selection process.

### Technologies Used
- **React** - For building dynamic and interactive UI components.
- **React Toastify** - To display customizable and real-time notifications.
- **Tailwind CSS** - A utility-first CSS framework to create responsive, attractive layouts.
- **JavaScript (ES6+)** - For efficient coding with modern JavaScript features.

### Key Features
1. **Responsive Interface**  
   The app is fully responsive, providing a seamless user experience across various devices and screen sizes.

2. **Real-Time Notifications**  
   Alerts are shown using React Toastify for actions such as adding or removing players, as well as budget-related notifications.

3. **Budget Management**  
   Enables users to track and manage a limited budget, adjusting automatically as players are added or removed.

### ES6 Features Used
- **Arrow Functions** for concise syntax.
- **Template Literals** for string interpolation.
- **Spread and Rest Operators** for handling arrays and objects.
- **Destructuring Assignment** for easily extracting values.
- **Modules** for organized and reusable code.
